Instructions for code, part A:
1. Compile the code by inputting `gcc -o lab lab7partA.c -lm -lpthread` into the terminal.
2. Run the code by inputting `./lab` with at least one positive integer argument. (e.g. `./lab 7 8 9`)
3. Output should be written onto the terminal.

Instructions for code, part B:
1. Compile the code by inputting `gcc -o lab lab7partA.c -lm -lpthread` into the terminal.
2. Run the code by inputting `./lab` with two positive integer arguments. The first argument
   represents the number of threads to spawn, while the second argument represents the number
   to be put into the sin() function. (e.g. `./lab 7 8`)
3. Output should be written onto the terminal.
